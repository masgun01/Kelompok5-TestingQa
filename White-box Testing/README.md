# White-box Testing

Pengujian Basis Path pada lima unit kode. Penanggung jawab: Gunawan Wibisono.

| Unit | Yang diuji | Berkas sumber |
|---|---|---|
| WB-01 | Pemeriksaan login | `auth/login.php` |
| WB-02 | Pemeriksaan registrasi | `auth/register.php` |
| WB-03 | Pemeriksaan upload berkas | `user/upload-berkas.php` |
| WB-04 | Aksi Terima dan Tolak | `admin/verifikasi.php` |
| WB-05 | Penyimpanan hasil seleksi | `admin/pengumuman.php` |

Tiap unit berisi flowchart, flow graph, hitungan Cyclomatic Complexity V(G), daftar jalur independen, dan test case per jalur beserta hasilnya.
