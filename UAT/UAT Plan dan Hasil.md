# UAT Plan dan Hasil

User Acceptance Testing memastikan sistem dapat dipakai oleh calon pengguna sebenarnya. Test case: TC-UA-01 sampai TC-UA-03 di [Test Case Sistem](../Test%20Case/Test%20Case%20Sistem.xlsx). Koordinator: Jumigih Andrian.

## Rencana

| Hal | Isi |
|---|---|
| Jenis | Alpha oleh tim penguji (seluruh test case), Beta oleh responden luar |
| Responden user | 3 orang calon orang tua atau wali murid |
| Responden admin | 1 orang petugas atau orang yang berperan sebagai admin |
| Akun | Disiapkan tim. Berkas contoh, bukan dokumen asli |
| Lingkungan | Website yang sama dengan pengujian, browser Chrome |

## Kriteria penerimaan

1. Lima tugas user selesai tanpa bantuan oleh minimal 2 dari 3 responden.
2. Tugas admin selesai tanpa bantuan.
3. Tidak ada defect Critical atau Major yang masih terbuka.
4. Rata-rata kepuasan minimal 4 dari 5.

Angka ini ditetapkan tim di Test Plan, bukan dari spesifikasi sistem.
